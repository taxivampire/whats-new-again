# 英文维护版 What’s New 写法

以下是美区 App Store 版本历史中的维护版。英文引号内是开发者原文节选。版本号便于核对；商店页面会继续更新。

| App 与版本 | 原文节选 | 可以借鉴的写法 |
| --- | --- | --- |
| [AllTrails 26.10.30](https://apps.apple.com/us/app/alltrails-hike-bike-run/id405075943) | “Minor bug fixes” | 一句感谢之后，只用三个词交代修复。事实少时，文案也可以短。 |
| [Headspace 8.31.0](https://apps.apple.com/us/app/headspace-sleep-meditation/id493145008) | “Thanks for using Headspace!” | 用感谢开场，再概括维护工作，最后给出求助渠道。只有产品提供了真实渠道才适合采用最后一步。 |
| [Slack 26.10.40、26.09.20](https://apps.apple.com/us/app/slack/id618783545) | “We tweaked some things too small to notice or too difficult to explain.” / “Trust us.” | 两个版本都归在 Bug Fixes 下。前者像团队给同事留话，后者用极短的第二句收尾。相同的说话人也可以换节奏。 |
| [Todoist 26.9.26、26.10.8](https://apps.apple.com/us/app/todoist-to-do-list-calendar/id572688855) | “A few fixes and flourishes, that’s all.” / “We told all the bugs to bug off.” | 一个版本轻描淡写，一个版本玩双关。两次都用同一句设置页引导收尾，品牌声音依然熟悉。 |
| [Strava 486.0.2](https://apps.apple.com/us/app/strava-run-bike-walk/id426826309) | “Have fun out there!” | 作者交代维护工作后，向即将去运动的人道别。语气来自使用场景。样本里的性能改进只属于 Strava 那一版。 |
| [Duolingo 7.146.0](https://apps.apple.com/us/app/duolingo-learn-languages/id570060128) | “trading in his usual diet of mice for bugs this week” | 借已有吉祥物 Duo 和 bugs 的双关写修复。只有用户熟悉的品牌设定才撑得起这种玩笑。 |

Slack 和 Todoist 在多个小版本里换说法。Strava 和 Duolingo 在相邻版本复用同一段。这个 Skill 按用户偏好避开旧句，同时保留同一产品的语气。选择一条最合适的手法即可，无需每次按表轮换。

苹果允许简单 bug 修复、安全更新和性能改进使用概括性说明，新功能和重大产品变化应写清楚。[App Review Guidelines §2.3.12](https://developer.apple.com/app-store/review/guidelines/#accurate-metadata)
